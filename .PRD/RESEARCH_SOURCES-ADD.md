# SEO, GEO 관련 내용

# https://chatgpt.com/share/6a43b386-4dcc-83ee-8664-ae13ba44bc88





아래는 **웹사이트/개발/마케팅에서 SEO·GEO와 같이 자주 묶이는 단어**만 핵심 요약한 것입니다.

| 용어                         | 뜻                                | 핵심 특징/기능                                               |
| ---------------------------- | --------------------------------- | ------------------------------------------------------------ |
| **SEO**                      | Search Engine Optimization        | 구글·네이버 같은 검색엔진이 사이트를 잘 이해하고 노출하도록 만드는 기본 최적화. 제목, 설명, 콘텐츠 구조, 링크, 속도, 모바일, 색인 관리가 핵심. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?utm_source=chatgpt.com)) |
| **Technical SEO**            | 기술 SEO                          | 검색엔진이 사이트를 잘 크롤링·색인하도록 돕는 기술 작업. sitemap, robots.txt, canonical, 페이지 속도, 모바일 대응, 오류 페이지 관리 등이 포함됨. ([Google for Developers](https://developers.google.com/search/docs?utm_source=chatgpt.com)) |
| **On-page SEO**              | 페이지 내부 SEO                   | 페이지 제목, 본문 구조, heading, 이미지 alt, 내부 링크, 키워드 배치처럼 페이지 안에서 하는 최적화. Google은 검색엔진이 콘텐츠를 이해하도록 돕는 것을 SEO의 핵심으로 설명함. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?utm_source=chatgpt.com)) |
| **Off-page SEO**             | 외부 SEO                          | 다른 사이트의 언급, 링크, 평판, 브랜드 신뢰도처럼 사이트 밖 신호를 높이는 작업. 실무적으로는 백링크·브랜드 인지도·외부 평판 관리와 연결됨. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?utm_source=chatgpt.com)) |
| **Local SEO**                | 지역 검색 최적화                  | “근처”, “지역명+서비스” 검색에 잘 나오도록 하는 최적화. 업체 정보, 위치, 리뷰, 지역 키워드가 중요함. |
| **GEO**                      | Generative Engine Optimization    | ChatGPT, Gemini, Perplexity, Google AI 검색 같은 생성형 AI 답변에 잘 언급·인용·추천되도록 콘텐츠를 정리하는 개념. Google은 GEO/AEO도 넓게 보면 검색 경험 최적화, 즉 SEO의 일부로 봄. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide?utm_source=chatgpt.com)) |
| **AEO**                      | Answer Engine Optimization        | AI 검색·음성검색·FAQ형 검색에서 “정답처럼 바로 제시”되도록 만드는 최적화. 질문-답변 구조, 명확한 정의, 신뢰 가능한 근거가 중요함. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide?utm_source=chatgpt.com)) |
| **LLMO**                     | Large Language Model Optimization | LLM이 브랜드·서비스·콘텐츠를 정확히 이해하도록 웹 전반의 정보 일관성, 명확한 설명, 신뢰 신호를 정리하는 개념. GEO/AEO와 거의 비슷한 맥락으로 쓰임. |
| **Structured Data**          | 구조화 데이터                     | 검색엔진이 페이지 의미를 더 명확히 이해하도록 표준 형식으로 정보를 표시하는 것. Google은 구조화 데이터를 “페이지 정보를 제공하고 콘텐츠를 분류하는 표준 형식”이라고 설명함. ([Google for Developers](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data?utm_source=chatgpt.com)) |
| **Schema.org**               | 구조화 데이터 표준                | 웹페이지, 이메일 등에서 구조화 데이터를 넣기 위한 표준 어휘. 검색엔진과 애플리케이션이 콘텐츠 의미를 이해하는 데 사용됨. ([Schema.org](https://schema.org/?utm_source=chatgpt.com)) |
| **SERP**                     | Search Engine Results Page        | 검색 결과 페이지. SEO는 이 SERP에서 더 잘 보이게 만드는 것이 핵심 목표. |
| **Crawling**                 | 크롤링                            | 검색엔진 봇이 웹페이지를 발견하고 읽는 과정.                 |
| **Indexing**                 | 색인                              | 검색엔진이 읽은 페이지를 검색 DB에 저장하는 과정.            |
| **Ranking**                  | 순위 결정                         | 검색어에 대해 어떤 페이지를 위에 보여줄지 판단하는 과정.     |
| **Canonical**                | 대표 URL 지정                     | 비슷하거나 중복된 페이지 중 어떤 URL을 대표로 볼지 알려주는 설정. |
| **Sitemap**                  | 사이트맵                          | 검색엔진이 사이트의 페이지 목록을 쉽게 찾도록 제공하는 파일. |
| **robots.txt**               | 크롤링 제어 파일                  | 검색엔진 봇이 접근해도 되는 영역과 피해야 할 영역을 안내하는 파일. |
| **Meta Title / Description** | 제목·설명 메타태그                | 검색 결과에 보일 수 있는 페이지 제목과 요약 설명. 클릭률과 페이지 이해에 중요함. |
| **Alt Text**                 | 이미지 대체 텍스트                | 이미지 내용을 텍스트로 설명해 검색엔진과 접근성 도구가 이해하도록 돕는 속성. |
| **E-E-A-T**                  | 경험·전문성·권위·신뢰             | 콘텐츠 품질과 신뢰성을 판단할 때 자주 언급되는 기준. 특히 AI 검색/GEO에서도 신뢰 신호로 중요해짐. |
| **geo / Geolocation**        | 위치 정보 기능                    | 개발에서 소문자 `geo`는 보통 SEO가 아니라 위치 기반 기능을 뜻함. 브라우저 Geolocation API는 사용자가 허용할 때 웹앱이 위치 정보를 받을 수 있으며, 개인정보 보호 때문에 권한 요청이 필요함. ([MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API?utm_source=chatgpt.com)) |

## 아주 짧은 결론

```txt
SEO = 검색엔진에 잘 노출되기 위한 최적화
GEO = AI 답변에 잘 언급·추천되기 위한 최적화
AEO = 질문에 대한 ‘바로 답변’으로 선택되기 위한 최적화
Structured Data / Schema = 검색엔진·AI가 내용을 더 잘 이해하게 만드는 구조화 표시
geo = 개발에서는 위치 정보, 지도, GPS 기능을 뜻할 수 있음
```

## 10번 검증 요약

```txt
1. SEO 정의 확인: Google 공식 문서 기준으로 확인
2. GEO 정의 확인: Google AI 최적화 문서 + GEO 연구 논문 기준으로 확인
3. AEO 정의 확인: Google 문서와 최신 업계 자료 기준으로 확인
4. geo와 GEO 혼동 방지: 위치 정보 API와 AI 검색 최적화를 분리
5. Structured Data 확인: Google 공식 문서 기준으로 확인
6. Schema.org 확인: Schema.org 공식 사이트 기준으로 확인
7. 개발 관련 의미 포함: Geolocation API 포함
8. 마케팅 관련 의미 포함: SEO, GEO, AEO, LLMO 포함
9. 홈페이지 제작 실무 용어 포함: sitemap, robots.txt, canonical, meta 포함
10. 과장 표현 제거: “무조건 상위 노출” 같은 보장성 문구 제외
```

## 타당한 근거/증거

Google 공식 문서는 SEO를 “검색엔진이 콘텐츠를 이해하고 사용자가 사이트를 찾도록 돕는 작업”으로 설명합니다. Google의 AI 검색 최적화 문서는 AEO와 GEO를 AI 검색 경험에서의 가시성을 높이는 용어로 설명하면서, Google Search 관점에서는 여전히 SEO의 일부라고 봅니다. MDN과 W3C 계열 문서는 Geolocation이 사용자의 명시적 권한이 필요한 위치 정보 기능임을 설명합니다. 따라서 **SEO/GEO/AEO는 검색·AI 노출 최적화 영역**, **geo는 개발에서 위치 기반 기능 영역**으로 구분하는 것이 타당합니다. ([Google for Developers](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?utm_source=chatgpt.com))
