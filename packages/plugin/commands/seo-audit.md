`$1`로 전달된 URL을 대상으로 `seomedic` MCP 서버의 `seomedic_audit` 도구를 호출해 기술 SEO 진단을 실행하라.

- 인자가 없으면 사용자에게 진단할 URL을 먼저 물어라.
- 사이트 전체 크롤이 필요하면(`--site` 의도) 기본값(max-pages 200 · depth 3 · rate-limit 1 req/s)을 그대로 쓰되, 사용자가 명시적으로 다른 값을 요청하면 그 값으로 전달하라.
- **반드시 확인할 것**: 이 URL이 사용자 본인 소유이거나 진단 권한이 있는 사이트인지 먼저 사용자에게 확인하라. 확인 없이 제3자 사이트를 대량 크롤하지 마라.
- 결과는 Markdown 리포트로 보여주고, `overall_score`는 절대 점수가 아니라 참고 라벨임을 함께 안내하라.
- 이 명령은 **분석 전용**이다 — 어떤 소스 파일도 수정하지 않는다.
